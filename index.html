Track your remaining usage ata glance.

UseReserve is a lightweight macOS menu bar app that keeps your remaining Codex, Claude, Cursor, and Grok Bot usage visible without interrupting your work.

Open Codex, Claude Desktop, Cursor, or Grok Bot once, then launch UseReserve to see the limits available on your Mac. macOS may ask permission before UseReserve can read a protected local sign-in.

The UseReserve app is read-only and never stores credentials, cookies, or message content. It reads only the local sign-in information each installed provider needs for an ephemeral usage request. This website uses privacy-first Cloudflare Web Analytics to count visits and page performance without cookies or personal profiles.

Menu bar
Open UseReserve again if its icon is missing. If your menu bar is crowded, close an unused menu-bar app so macOS has room to show it.
Sign-in
Open Codex, Claude Desktop, Cursor, or Grok Bot and confirm you are signed in, then return to UseReserve.
Claude permission
Choose Connect Claude in UseReserve and approve access to Claude Safe Storage when macOS asks.
Cursor usage
Cursor must be installed and signed in. UseReserve shows Cursor and Other Models when those limits are available for your individual plan.
Grok Bot usage
Grok Bot must be installed. UseReserve prefers the account signed into Grok Bot, then falls back to Cursor's sign-in if that account is unavailable or rejected. When Cursor fallback is active, choose Use Grok Bot Sign-In to switch accounts; if macOS blocks Grok Bot Safe Storage, choose Allow Grok Bot Access.
Stale readings
UseReserve keeps the last available reading during a temporary outage and shows when it was last updated.
Refresh
Open the more menu and choose Refresh after reconnecting to the internet or signing in again.
Hiding an app
Open the more menu and untick an app under Show/Hide to drop it from the panel. It stops being polled until you tick it again.
Login Items
If UseReserve does not start automatically, open System Settings → General → Login Items and enable UseReserve.
